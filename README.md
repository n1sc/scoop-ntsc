# scoop-ntsc

Scoop bucket for [ntsc](https://github.com/n1sc/ntsc) — the Neutron Type-Safe
Compiler: a statically typed, memory-safe systems language compiled through
LLVM.

```powershell
scoop bucket add n1sc https://github.com/n1sc/scoop-ntsc
scoop install ntsc
```

`bucket/ntsc.json` is generated and pushed by the release workflow in
[n1sc/ntsc](https://github.com/n1sc/ntsc) whenever a `v*` tag is pushed. Edit it
there, not here.
